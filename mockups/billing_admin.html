Generate monthly billing run

Policy: generate on/after day 28 of the month. Only one run may exist per month.

A finalized run already exists for June 2026. Finalized runs cannot be regenerated — use per-line status overrides for corrections.
A draft run already exists for July 2026 (not yet sent to Finance).
Generation creates one line per project + enabled fee-bearing EM, snapshots each project's current PTA, and re-creates any still-unpaid (rejected/hold) lines from prior months as carry-forward attempts billed to the project's current PTA. Projects without a PTA mapping get hold lines under “Unmapped”.
Development projects: lines inside the module's first 90 days are included as grace ($0, excluded from the Finance CSV). Once the 90-day window ends the line bills at full fee regardless of project status — and moving the project to Production ends the grace immediately.

Expiration alerts: a nightly job emails each PTA's contact (and the projects' PIs) two months before the expiration date, asking them to renew the PTA or map projects to a new one. If the date passes with no replacement, the modules billed to that PTA are disabled automatically — any unpaid charges remain in Outstanding Balances.
Open balance links to Outstanding Balances — an expired PTA with debt is the classic backcharge case: assign the project a new PTA on the Mapping tab and next month's run re-bills the full amount to it.
Project ↔ PTA mapping
PTA changes affect future runs only. Already-generated lines keep their snapshot PTA; open rejected/hold debt automatically re-bills to the project's current PTA at the next monthly run — that's how a backcharge lands on a replacement PTA. Mappings are created/updated automatically when a PI approves a request; edit here only to correct one.
